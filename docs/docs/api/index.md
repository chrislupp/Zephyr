# API Reference

The crate is `zephyr-vlm` and is imported as `zephyr_vlm`. These sheets cover
the types where the **semantics** matter more than the signature: what a call
assumes, what it invalidates, what convention it reports in. Item-level
documentation for everything else is generated by rustdoc and published on
[docs.rs](https://docs.rs/zephyr-vlm); `cargo doc --open` builds the same pages
for a checkout.

## Modules

| Module | Contents |
| --- | --- |
| `core` | scalar and vector aliases, constants, `SymmetryType`, `SpacingType` |
| `geometry` | `Aircraft`, `Surface`, `Section`, `Airfoil`, `Body`, and the direct-mesh types |
| `solver` | lattice generation, influence assembly, `VortexLatticeSolver` |
| `aero` | `ForceCalculator`, `StabilityDerivativeCalculator`, and their result types |
| `analysis` | the request-driven `Analysis` interface and half-wing mode |
| `gradients` | analytical kernels, adjoints, `GradientCalculator`, `StripLoadAdjoint` |
| `trim` | constraints and presets, `TrimSolver`, `MeshTrimSolver` |
| `dynamics` | `MassProperties`, `FlightState`, `EigenmodeAnalysis` |
| `io` | `AvlReader`, `MassReader` |
| `visualization` | `VtkExporter`, behind the default `vtk` feature |
| `philote` | Philote-MDO gRPC disciplines, behind the non-default `philote` feature |
| `error` | `ZephyrError`, `Result`, `ParseLocation` |

## Core types

```rust
use zephyr_vlm::core::{Scalar, Vec3, MatX, VecX};
```

`Scalar` is `f64` throughout; there is no generic precision parameter and no
single-precision path. `Vec3`, `Mat3`, `VecX`, and `MatX` are nalgebra aliases,
so anything nalgebra can do to them is available.

Constants: `PI`, `DEGREES_TO_RADIANS`, `RADIANS_TO_DEGREES`, `EPSILON`
(`1e-12`), `DEFAULT_TOLERANCE` (`1e-10`).

## Two geometry paths

Every analysis entry point accepts either, and they are not interchangeable
spellings of the same model:

| | Section model | Direct mesh |
| --- | --- | --- |
| Type | `geometry::Aircraft` | `geometry::MeshInput` |
| Solver | `set_aircraft` | `set_mesh` |
| Forces | `compute_for_aircraft` | `compute_with_references` |
| Gradients | section variables | node coordinates |
| Controls | `ControlSurfaceDefinition` | `MeshControlSurface` |
| Trim | `TrimSolver` | `MeshTrimSolver` |

See [Geometry](../guide/geometry.md) for which to choose.

## Conventions

Axes, units, signs, coefficient definitions, and panel ordering are stated once
in [Conventions](../getting-started/conventions.md). Two that catch everyone:
section twist and surface incidence are in **degrees** while everything else
angular is in radians, and **all three** moment coefficients — roll, pitch, and
yaw — are normalized by the reference chord.

## Errors

Fallible calls return `Result<T, ZephyrError>`. See [Errors](./errors.md).
