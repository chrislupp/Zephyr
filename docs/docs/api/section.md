# Section

`Section` defines leading edge, chord, twist in degrees, an optional owned
`Airfoil`, spanwise overrides, viscous data, ordered controls, and design
metadata. A section without a custom airfoil evaluates as a shared flat plate.

See the [`Section` rustdoc](https://docs.rs/zephyr-vlm/latest/zephyr_vlm/geometry/struct.Section.html).
